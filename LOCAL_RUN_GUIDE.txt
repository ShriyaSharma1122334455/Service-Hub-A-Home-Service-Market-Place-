PREREQUISITES
-------------
- Node.js v18+ (check: node --version)
- npm v9+ (check: npm --version)
- Git
- VS Code (recommended: install ESLint + Tailwind CSS IntelliSense extensions)


STEP 1 — CLONE / PULL LATEST
-----------------------------
If you already have the repo cloned:

  cd /Users/deep_anmol/Desktop/ServiceHub_Deep/ServiceHub_Shriya
  git checkout main
  git pull origin main

If cloning fresh:

  git clone https://github.com/ShriyaSharma1122334455/Service-Hub-A-Home-Service-Market-Place-
  cd Service-Hub-A-Home-Service-Market-Place-


STEP 2 — BACKEND SETUP
-----------------------
2a. Install dependencies:

  cd backend
  npm install

2b. Create the .env file:

  Copy backend/.env.example to backend/.env
  Fill in the actual values (ask Shriya for Supabase credentials):

    NODE_ENV=development
    PORT=3000
    SUPABASE_URL=https://<project>.supabase.co
    SUPABASE_SERVICE_ROLE_KEY=<service_role_key>
    JWT_SECRET=any-random-string-for-local-dev
    CORS_ORIGIN=http://localhost:5173

  Optional (only if testing email/image features):
    RESEND_API_KEY=...
    CLOUDINARY_CLOUD_NAME=...
    CLOUDINARY_API_KEY=...
    CLOUDINARY_API_SECRET=...

2c. Start the backend:

  npm run dev

  Expected output: "Server is running on port 3000" + "Supabase connected"
  Backend runs at: http://localhost:3000


STEP 3 — FRONTEND SETUP
------------------------
Open a new terminal tab.

3a. Install dependencies:

  cd frontend
  npm install

3b. Create the .env file:

  Copy frontend/.env.example to frontend/.env
  Fill in the actual values:

    VITE_SUPABASE_URL=https://<project>.supabase.co
    VITE_SUPABASE_ANON_KEY=<anon_key>
    VITE_API_BASE_URL=http://localhost:3000

3c. Start the frontend:

  npm run dev

  Expected output: "Local: http://localhost:5173/"
  Frontend runs at: http://localhost:5173

================================================================
 COMMON ERRORS & FIXES
================================================================

Error: "Network Error" on API calls
  → Backend not running. Make sure `npm run dev` is active in /backend

Error: "Failed to fetch" / CORS error
  → Check CORS_ORIGIN in backend/.env matches http://localhost:5173

Error: "Supabase connection failed"
  → Check SUPABASE_URL and SUPABASE_SERVICE_ROLE_KEY in backend/.env

Error: Login rate limited
  → Wait 15 mins OR use Supabase direct auth:
    curl -X POST "$SUPABASE_URL/auth/v1/token?grant_type=password" \
      -H "apikey: $SUPABASE_ANON_KEY" \
      -d '{"email":"deep_user1@yopmail.com","password":"TestPass123!"}'

Error: "0 providers available" on service page
  → Known issue: provider_services junction table may be empty in DB
    Ask Shriya to check the provider_services table seeding

Error: Frontend blank page
  → Check browser console (F12). Usually means .env values are missing.

Error: TypeScript build error
  → Run `npm run build` in /frontend to see full error
  → Run `npx eslint src` to catch lint errors

================================================================
 API ENDPOINTS QUICK REFERENCE
================================================================

Auth:
  POST /api/auth/register
  POST /api/auth/login
  POST /api/auth/logout

Services:
  GET  /api/services
  GET  /api/services?category=Cleaning

Providers:
  GET  /api/providers
  GET  /api/providers/:id
  GET  /api/providers/by-service/:serviceId
  GET  /api/providers/search?q=<name>&status=<status>

Bookings:
  GET  /api/bookings          (customer: their bookings)
  POST /api/bookings          (create booking)
  PATCH /api/bookings/:id     (update status)

Reviews:
  GET  /api/reviews/:providerId
  POST /api/reviews

Dashboard:
  GET  /api/dashboard/provider
  GET  /api/dashboard/customer

Chatbot:
  GET  /api/chatbot/context

Profile:
  GET  /api/profile/:id
  PATCH /api/profile/:id
